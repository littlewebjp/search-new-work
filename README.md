# LATTE

相談はいつものChatGPTで。助手が検索・提案し、会話や判断を記録します。LATTEは、助手の保存庫と、本人が状況だけを見る1ページのダッシュボードです。本人による入力や転記は不要です。

## ページの役割

- **新しい提案 → 判断待ち → 保留中 → 応募中**を1ページに表示。
- 1件は**勤務地・仕事内容・現在の状況**だけ。詳細はURLのみ。
- タブ、入力欄、会話一覧、プロフィール、説明パネルは置かない。
- 会話・判断理由・一度聞いた希望・作品や資料は裏側で記録し、助手が次の提案と応募準備に使う。

判断や修正の相談はこのチャットで行います。ページで選択を送ったことにしたり、準備済みを応募済みとして扱ったりしません。

○は応募待ち、▲は保留、×は会話で理由を聞いて記録します。○を記録する `application_queued` は書類準備前でも使えますが、実在求人の出典と本人の意思の参照が必要です。実際の応募済みは提出の証跡が必要です。

## 会話の反映方法

この作業環境のアシスタントが、会話の内容を `.latte/workspace.json` に記録し、公開が許可されている場合に暗号化スナップショットを送ります。ページはその最新版を読み込みます。反映範囲・最終反映日時・記録の版を画面で確認できます。

これはChatGPT全体の常時取得や双方向同期ではありません。別チャットや、この作業環境にアクセスできない会話は自動で入りません。作業環境が停止している間にLATTEがバックグラウンドで求人を調べる機能もありません。

## 開発・検証

Python 3.12+ と暗号化用の依存関係を使います。

```sh
python3 -m pip install -r requirements-sync.txt
python3 -m unittest discover -s tests -v
python3 build_dashboard.py --output-dir .latte/dashboard-public
```

`build_dashboard.py` が生成するのは汎用の画面と、明示的に架空とした画面例だけです。個人データベースを読みません。

会話の記録と非公開の確認用ビルド：

```sh
python3 sync_latte.py record --input .latte/session.json
python3 sync_latte.py build
python3 sync_latte.py status
```

送られた資料の保管と取り出し（1ファイル25MBまで）：

```sh
python3 sync_latte.py archive --file /path/to/file.pdf --title '本人から共有された作品集'
python3 sync_latte.py extract --asset-id ASSET_ID --output .latte/exports/portfolio.pdf
```

資料の原本は非公開の `.latte/vault/` に保管します。公開する場合も、本体は暗号化し、元のファイル名と保管情報は暗号化された会話記録の中にのみ含めます。出力先は上書きしません。

`record` は安定したIDで追記・更新し、引用と会話の参照を検証します。`build` はローカルに暗号化ファイルを作るだけで、公開しません。公開には別途、暗号化データを公開GitHubへ保存することへの本人の同意が必要です。詳しくは [PUBLISH.md](PUBLISH.md) を参照してください。

## 個人情報と鍵

会話の平文・プロフィール・鍵・専用URLはGit管理から除外した `.latte/` に保存します。暗号化した会話の公開保存は、コード公開とは別の同意として扱います。専用リンクを知る人は記録を読めるため共有しないでください。

公開GitHubに残る暗号化データの履歴は、端末の接続解除で消えません。鍵を失った場合は、新しい鍵を勝手に作らず元の非公開バックアップから復元します。クラウド環境のスナップショットとGitのソース管理は別です。

## 旧版について

`latte.py` / `web/` / `build_offline.py` は旧ローカルノート版です。旧版のブラウザーメモは自動送信・自動移行・削除しません。現在のダッシュボードとは保存先が異なります。
